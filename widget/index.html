Quote of the Day Widget

Put a fresh quote on your own website every day, automatically. The QuotePlace widget loads today's quote from our daily data file and renders it in a clean card — no API key, no account, nothing to maintain. The only condition: the built-in “via QuotePlace” link stays in place.

Add it to your site

Paste this snippet where you want the quote to appear:

<div id="quoteplace-qotd"></div>
<script src="https://quoteplace.vercel.app/widget/qotd.js" async></script>

The widget is dependency-free vanilla JavaScript. It fetches qotd.json once, renders with text nodes (no HTML injection), and does nothing if the fetch fails. Prefer a feed? The same quote is published as RSS.
